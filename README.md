# 17歩 ONLINE v0.4.32 PCダブルクリック修正版

## すぐ遊ぶ
index.html をブラウザで開き、スマホを横向きにして「COMと対戦」を選びます。
Firebaseは不要です。

## COM戦で入っているもの
- 136枚・赤ドラなし
- 自分34枚 / COM34枚
- 表ドラ公開
- 3分手作り
- 13枚テンパイ時のみ確定
- 時間切れランダム補充
- COMも13枚を自動選択
- 最大17回の交互捨て
- ロン / 見逃し10秒
- フリテンの基本処理
- 裏ドラはロン後のみ
- 流局親継続
- 獲得金額

## 注意
役判定はまだ完全版ではありません。
現在は和了形、リーチ、タンヤオ、七対子、三元牌、ドラ、一発、河底、国士無双などの主要部分を先に実装しています。

オンライン戦は別途Firebase接続版を継続開発します。

## v0.4.23 最強CPU
CPU難易度を「最強」に固定。

### 13枚の手作り
- 以前のランダムなテンパイ探索を廃止
- 自分の34枚から作れる「4面子1雀頭」「七対子」「国士無双」のテンパイ候補を体系的に生成
- 候補ごとに以下を比較
  - 4飜以上でロンできる待ちか
  - 待ちの種類
  - CPUの34枚以外に残る待ち枚数
  - 親 / 子による獲得金額
  - 役満・高打点
  - 自分の21枚側に待ち牌が残りすぎてフリテンにならないか
- 裏ドラは非公開情報なのでCPUの判断には使用しない
- 相手の固定13枚も参照しないため、隠し情報を使った作弊はしない

### 捨て牌
- CPU自身の待ち牌は、切らずに済む限り絶対に切らない
- 相手の河にある同一牌を最優先の安全牌として扱う
- CPUが多く持つ牌、公開済み牌の多い牌を安全寄りに評価
- ドラ、相手の自風、三元牌、中央の数牌を危険寄りに評価
- 相手の河の色の偏りも軽く考慮
- 相手がフリテンなら、普段なら危険な牌を先に処理
- 一発が付く序盤はさらに守備重視

### CPU専用方針
- 現段階ではオンライン対戦ボタンを外し、CPU対戦版の完成を優先
- 対人戦はCPU版完成後に追加予定

PWAキャッシュ名は `17po-online-v0.4.23`。
