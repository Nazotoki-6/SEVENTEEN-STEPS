# 17歩 ONLINE v0.4.1 COM対応・不具合修正版

## すぐ遊ぶ
index.html をブラウザで開き、スマホを横向きにして「COMと対戦」を選びます。
Firebaseは不要です。

## COM戦で入っているもの
- 136枚・赤ドラなし
- 自分34枚 / COM34枚
- 表ドラ公開
- 3分手作り
- 13枚テンパイ時のみ確定
- 時間切れランダム補充
- COMも13枚を自動選択
- 最大17回の交互捨て
- ロン / 見逃し10秒
- フリテンの基本処理
- 裏ドラはロン後のみ
- 流局親継続
- 獲得金額

## 注意
役判定はまだ完全版ではありません。
現在は和了形、リーチ、タンヤオ、七対子、三元牌、ドラ、一発、河底、国士無双などの主要部分を先に実装しています。

オンライン戦は別途Firebase接続版を継続開発します。
